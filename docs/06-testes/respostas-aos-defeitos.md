# Respostas aos defeitos recebidos

> Preencher apos a Empresa 02 testar a versao congelada. Nao registrar resposta sem caso recebido.

| Caso | Severidade | Decisao | Fundamentacao ou correcao | Commit/versao | Reteste |
|---|---|---|---|---|---|
| | | Acatado / Contestado / Fora do escopo | | | |

## Regras de triagem

- **Acatado:** comportamento viola requisito/contrato; corrigir e testar regressao.
- **Contestado:** resultado esta correto; citar requisito, ADR ou evidencia tecnica.
- **Fora do escopo:** citar a declaracao de escopo, sem usar isso para esconder falha de feature obrigatoria.
- Defeito critico ou alto exige avaliacao imediata do GP e arquiteta.
